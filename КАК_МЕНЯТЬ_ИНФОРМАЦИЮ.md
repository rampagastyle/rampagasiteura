## 2. КАТАЛОГ АВТОМОБИЛЕЙ И ИХ ФОТОГРАФИИ: `src/data/carsData.ts`
> Здесь задаются автомобили, их характеристики, комплектации, цены и **3 ракурса фото** (фас, профиль, салон).

Каждая машина оформлена как отдельный понятный блок:

```typescript

  brand: 'X-Line',                    // Бренд / марка для фильтра

  price: 2450000,                     // Цена цифрой в рублях
  oldPrice: 2620000,                  // Старая перечеркнутая цена (если есть скидка)
  monthlyPayment: 18900,              // Ежемесячный платёж по кредиту
  year: 2026,                         // Год выпуска модели (2026)
  engine: '2.0 л, 150 л.с.',          // Двигатель
  power: 150,                         // Мощность в л.с.
  fuel: 'Бензин',                     // Бензин / Дизель / Электро / Гибрид
  transmission: 'АКПП',               // АКПП / МКПП / Вариатор / Робот
  drive: 'Передний',                  // Передний / Полный / Задний
  acceleration: '9.8 сек',            // Разгон до 100 км/ч

    front: '/images/cars/xline-front.jpg',    // 1. Фас (вид спереди)
    side: '/images/cars/xline-side.jpg',      // 2. Профиль (вид сбоку)
    interior: '/images/cars/xline-inside.jpg' // 3. Салон (интерьер)
  },
  
  // Комплектация и опции:
  features: [
    'Климат-контроль 2-зонный',
    'Мультимедиа 10.25" с Apple CarPlay',
    'Камера кругового обзора 360°'
```

## 3. УСЛУГИ, АКЦИИ И ФОТОГАЛЕРЕЯ: `src/data/dealershipData.ts`
В этом файле редактируются:
- **`PROMOTIONS`** — акции и спецпредложения (название акции, период действия, размер выгоды, фото);
- **`SERVICES`** — услуги (Кредит, Трейд-ин, Страхование, Сервисный центр, ГИБДД);
- **`ADVANTAGES`** — 6 преимуществ автосалона (процент кредита, гарантия 3 года и т.д.);
- **`GALLERY_ITEMS`** — фотографии для фотогалереи с разбивкой по вкладкам (*Шоурум*, *Автомобили*, *Сервис*, *Команда*).

## 4. КАК ЗАГРУЗИТЬ СВОИ ФОТОГРАФИИ С КОМПЬЮТЕРА

Вы можете подгружать фотографии двумя удобными способами:

### Способ А: Локальные файлы с компьютера (рекомендуется)
1. Откройте папку `public/` в корне проекта.
2. Создайте в ней удобную структуру (или положите прямо в `public/images/`):
   ```
   public/
     images/
       facade.jpg
       showroom.jpg
       cars/
         car1-front.jpg
         car1-side.jpg
         car1-interior.jpg
   ```
3. В конфиге или каталоге укажите путь, начинающийся со слеша:
   ```typescript
   front: '/images/cars/car1-front.jpg'
   ```
   *Vite автоматически подключит эти изображения!*

### Способ Б: Ссылки на внешние фотографии в интернете
Вы можете просто вставить любую прямую ссылку вида:
```typescript
front: 'https://mysite.ru/photos/car.jpg'
```
